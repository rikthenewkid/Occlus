Política de Privacidade - Opencode

Última atualização: 23 de novembro de 2026

A Occlus ("nós", "nosso" ou "empresa") opera o aplicativo Opencode ("aplicativo"). Esta página informa sobre nossas políticas relativas à coleta, uso e divulgação de dados pessoais quando você usa nosso aplicativo ou se conecta a ele por meio de APIs de terceiros (como o Pinterest).

1. O que é o Opencode?

O Opencode é um conector de ambiente local baseado em MCP (Model Context Protocol). Ele permite que um agente de inteligência artificial (IA) autônomo crie, agende e gerencie Pins e pastas no Pinterest em nome do usuário autenticado.

2. Coleta e Uso de Dados

O Opencode foi projetado com o princípio de privacidade local. Nós não possuímos servidores que coletam ou armazenam seus dados.

Quais dados o aplicativo acessa?

  • Tokens de Acesso OAuth: Para se comunicar com a API do Pinterest, o aplicativo gera e utiliza um token de acesso. Este token é armazenado estritamente na máquina local onde o Opencode está instalado (em variáveis de ambiente ou arquivos locais seguros).
  • Dados de Pins e Pastas: O aplicativo lê os dados das suas pastas e Pins apenas para executar as ações solicitadas pelo agente de IA (ex: criar um novo Pin, buscar o ID de uma pasta).

Como esses dados são usados?

  • Exclusivamente para publicar o conteúdo no Pinterest e gerenciar as pastas em seu nome, conforme as instruções dadas pelo agente de IA.
  • Nós não vendemos, alugamos ou compartilhamos seus dados com terceiros.
  • Nós não usamos seus dados para publicidade ou criação de perfis.

3. Armazenamento e Segurança

Todas as credenciais de acesso (como o token OAuth) e os dados de Pins gerenciados pelo aplicativo residem apenas no computador do usuário. O usuário é responsável por manter a segurança do seu ambiente local e de suas chaves de API.

4. Serviços de Terceiros

O Opencode interage diretamente com a API oficial do Pinterest. O uso de dados pelo Pinterest é regido pela Política de Privacidade do próprio Pinterest. Recomendamos a leitura em: https://policy.pinterest.com/pt-br/privacy-policy.

5. Direitos do Usuário e Revogação de Acesso

Você pode revogar o acesso do Opencode à sua conta do Pinterest a qualquer momento. Para isso:

  1. Acesse sua conta do Pinterest.
  2. Vá em Configurações > Aplicativos conectados.
  3. Encontre o aplicativo Opencode e clique em Revogar acesso.
  4. No seu ambiente local, apague o token de acesso do Opencode.

6. Alterações nesta Política de Privacidade

Podemos atualizar nossa Política de Privacidade de tempos em tempos. Notificaremos você sobre quaisquer alterações publicando a nova Política de Privacidade nesta página. Recomendamos revisar esta página periodicamente para quaisquer alterações.
